Конфиденциальность

Обновлено: 28 октября 2026 года

Об этой политике

Разработчик Table Rivals: Pocket Pong — Aleksandr Shevliakov. Политика относится к приложению для iPhone/iPad и этому сайту, включая текущую закрытую бету. Вопросы и запросы о данных: littlegamesios@gmail.com.

Данные игры на устройстве

Приложение сохраняет настройки, например звук и сложность компьютера, и рекорд розыгрыша локально на вашем устройстве. У разработчика нет сервера, который получает или синхронизирует эти данные. Они могут попадать в резервную копию в соответствии с настройками Apple. Игра вдвоём на одном экране и матчи с компьютером работают без интернета.

Игра по сети через Game Center

Для матча с другом на другом устройстве используются Game Center Apple и интернет. Игра использует отображаемое имя и идентификатор игрока Game Center для подключения и показа соперника, а через GameKit передаёт состояние матча: позиции мяча и ракеток, готовность игроков и счёт. Эти данные не отправляются на сервер разработчика. Apple обрабатывает данные аккаунта, активности и сервиса Game Center по своим правилам. Видимость и ограничения сетевой игры настраиваются в системе Apple. Подробнее — в уведомлении Apple о конфиденциальности Game Center.

Без рекламы и аналитических SDK

В приложении нет рекламы, сторонних аналитических SDK, пикселей отслеживания, чата и загрузки пользовательского контента. Отдельный аккаунт Table Rivals создавать не нужно. Необязательная полная версия оплачивается один раз через Apple StoreKit. Приложение проверяет подтверждённое право на покупку и может восстановить доступ с вашим Apple Account. Мы не получаем данные банковских карт и не отправляем историю покупок на сервер разработчика. Apple может обрабатывать диагностику и отзывы TestFlight по своей политике конфиденциальности.

Этот сайт

Статический сайт размещён на GitHub Pages. На нём нет аналитики, cookies, пикселей отслеживания, внешних шрифтов и встроенных видео. GitHub может обрабатывать сведения о запросах, например IP-адреса, для работы и защиты хостинга согласно GitHub General Privacy Statement. Изображения и скрипты загружаются вместе с сайтом.

Данные аккаунта Game Center, видимость и ограничения сетевой игры для детей настраиваются средствами Apple.
